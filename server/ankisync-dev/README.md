# ankisync-dev

Official Anki sync server (`python -m anki.syncserver`, PyPI `anki==26.9.3`) + Caddy TLS terminator, for **local
development and tests only**. Used by `compose.dev.yml` at the repo root.

- `Dockerfile` — server image (`python:3.12-slim-bookworm`, non-root, healthcheck on `/health`, includes `pyclient.py`)
- `Caddyfile` — TLS on `:8443` with the dev certificate, proxies to `ankisync-dev:8080`
- `pyclient.py` — official Anki Python client against this server only (cross-check of the app's sync)
- `certs/` — generated by `scripts/ankisync-dev-certs.sh` (gitignored)

Full notes: [docs/tecnico/anki-sync-dev.md](../../docs/tecnico/anki-sync-dev.md).
